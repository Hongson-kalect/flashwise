1. **Pipeline lệch pha giữa các step**: mỗi step đã là một run độc lập (state + `.lock`), cần bộ điều phối để step N refine trong khi step N+1 draft (vd 1.000 từ mỗi step). Poll mỗi run 30-60s để dưới 50 request/phút ở tier Evaluation.

Mỗi ngôn ngữ một consumer (cùng ngôn ngữ phải tuần tự vì ứng viên phụ thuộc quyết định trước; khác ngôn ngữ gần như độc lập). Mỗi consumer ~43k nghĩa / ngày.
